lume · abac

进程内 ABAC 授权

站点在自己的进程里完成每一次授权决策 —— 没有独立的策略服务，没有决策时的网络往返。 决策引擎 shared/abac.lume 被站点 import 进来，与站点同源、同一份逻辑。

默认拒绝（deny-by-default）：七步检查链任一不通过即短路返回 DENY， 且每次拒绝都写入审计。

    abac.lume 决策引擎
    
      
    七步 deny-by-default 检查链：认证 → 资源 → 动作 → 账号 → 角色 → 学段 → 环境。只依赖传进来的资源表与账号表，不发起任何网络请求。
    
    
    
    
    
      
    admin.lume 账号 / 授权写口
    
      
    账号 CRUD、学段授权、密码哈希热重载；接入中央身份后自动拒绝本地写操作。
    
    
    
    
    
      
    本演示站点不暴露 admin 写口
    
      
    身份权威只能有一个。若这里也开放账号写入，就会出现第二个写入方 —— 那正是这套模型要避免的。所以 admin 的能力只由 kb-auth 与各站点的授权端点承担。
